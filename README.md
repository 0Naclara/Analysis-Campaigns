
# Predictive Campaign Analysis

Aplicação web interativa para análise preditiva e simulação de retorno em campanhas de mídia paga.

## Funcionalidades
- **Simulador em Tempo Real:** Previsão de conversões, receita estimada, lucro líquido e ROAS com base na plataforma, objetivo, interesse do público, formato do anúncio e orçamento.
- **Curva de Retorno:** Projeção visual do crescimento de receita conforme o aumento do investimento.
- **Comparativo Histórico:** Análise de desempenho médio (ROAS) entre diferentes canais de aquisição.

## Tecnologias Utilizadas
- **Python**
- **Streamlit** (Interface web e deploy)
- **Pandas** (Manipulação de dados)
- **Scikit-Learn** (Modelo de regressão `RandomForestRegressor`)
- **Plotly** (Gráficos interativos)
